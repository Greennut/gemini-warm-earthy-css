## Highlights

* **Warm Paper Surface**: Reduces glare and eye strain using `#FBF9F5` background tone.
* **Native Input Geometry**: Overrides color via official CSS variables without breaking the native capsule expansion animation.
* **32px Modern Code Block**: Smooth border-radius with unified pure white container and border-bottom styling.
* **Balanced Typography**: 16px font size with 1.75 line height for high-DPI clarity.
* **Single-Hue Earthy Syntax**:
  * **Keywords & Tags**: Terracotta Red (`#A33D2C`)
  * **Classes, Attributes & `!important`**: Dusty Rose (`#D05A6E`)
  * **Functions & Types**: Slate Mineral Blue (`#4B789B`)
  * **Strings**: Olive Green (`#6C8B35`)
  * **Numbers & Booleans**: Deep Goldenrod (`#B8860B`)

## Quick Install

1. Install **Stylus** ([Chrome](https://chromewebstore.google.com/detail/stylus/clngdbkpkpeebahjckkjfobafhncgmne) / [Firefox](https://addons.mozilla.org/en-US/firefox/addon/styl-us/)).
2. Open Stylus, click **Write new style**, and paste the CSS code from `gemini-warm-earthy.user.css`.
3. Set domain rule: Applies to URLs on the domain `gemini.google.com`.
4. Save and refresh your Gemini tab.
